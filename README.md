# 两个人的练习室

几个很短的像素小游戏，用来练习亲密关系里最难的那些事：怎么问，怎么听，以及怎么判断两个人到底合不合适。

**在线游玩：** https://cudada-jpg.github.io/her-words/

---

## 01 · 她想说的话

`ask/` · https://cudada-jpg.github.io/her-words/ask/

今晚，她提出了分手，但没有说为什么。你有四次开口的机会：问对了，她的心门会一点点打开，说出真正的原因；问错了，她的耐心会减少，三次就会离开。

- **心门**：好的提问（倾听、好奇、共情、承认）让它上升。到 40 / 55 / 70 时各解锁一块"原因碎片"。
- **耐心**：辩解、猜疑、轻视、回避会扣一颗心，三颗扣完她就走了。
- 三个夜晚：看不见的我 / 远方的 offer / 每次吵架之后，共 6 种结局。

## 02 · 咬合

`fit/` · https://cudada-jpg.github.io/her-words/fit/

两个人在一起，像两个齿轮。合的地方，齿轮自己会转；不合的地方，每转一次都要多花一点力气。

1. 回答 5 个关于你自己的问题：社交充电、金钱观、亲密距离、冲突方式、人生方向。
2. 从三个人里选一个：很像你的 Ta / 不太一样的 Ta / 让你心动的 Ta。
3. 和 Ta 过完一年。每个月一件小事，你可以迁就、坚持、商量或先不谈。

游戏想讲清楚的事：

- **摩擦税**：每一处不合，都要每天付一点能量，而且越付越贵。
- **核心差异**：在哪里生活、想过怎样的人生，这类问题没法各退一步。
- **怎么走到分手**：迁就会让人慢慢消失，坚持会积累冲突，不谈会让问题积压，最后出现批评、防御、冷战、蔑视（Gottman 的"四骑士"），直到两个人都没力气了。
- **合适是什么**：核心方向一致、摩擦税付得起、吵得开也修得好、差异被欣赏而不是被忍受。
