# 她想说的话

今晚，她提出了分手，但没有说为什么。你有四次开口的机会：问对了，她的心门会一点点打开，说出真正的原因；问错了，她的耐心会减少，三次就会离开。

**在线游玩：** https://cudada-jpg.github.io/her-words/

## 玩法

- **心门**：好的提问（倾听、好奇、共情、承认）让它上升，房间变暖，她会转过身、走近你。到 40 / 55 / 70 时各解锁一块"原因碎片"。
- **耐心**：辩解、猜疑、轻视、回避会扣一颗心，三颗扣完她就走了。
- 心门达到 70，她会说出完整的原因，你还要选择怎么回应。
- 每次选择后都有一条沟通点评，结局页有完整复盘和一句"带回现实的话"。

## 三个夜晚

1. **看不见的我**：她升职那天，你头都没抬。
2. **远方的 offer**：她要去成都，可真正的原因不是工作。
3. **每次吵架之后**：她不怕吵架，怕的是吵完你消失。

共 6 种结局。数字键 1–4 选择，空格 / 回车 跳过打字。

## 运行

单个 `index.html`，无需构建，直接用浏览器打开即可。
